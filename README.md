# HeavenHell

# CSIM2025-IM-Group03

# 

# A dual VR experience exploring the contrast between Creation (Heaven) and Corruption (Hell) through reactive physics and audiovisual changes.

# 

# 🎮 Controls (Inputs)

# Select World (Start Screen): X Button (Left Controller).

# Return to Main Menu: Left Grip (Side Button).

# Locomotion: Left Joystick.

# Turning: Right Joystick.

# Interaction: Index Trigger (Raycast aiming).

# 

# ✨ Features \& Interactions

# The virtual environment reacts differently depending on the active world state (Heaven or Hell).

# 

# 1\. Energy Streams (Particles)

# Action: Aim at the particle stream and Hold Trigger.

# ⚪ Heaven (The Creator): Harmonization. Particles turn golden, become brighter, and flow faster with celestial audio.

# ⚫ Hell (The Corruptor): Decay. Particles turn gray and fade away (drain) until they vanish, accompanied by silence or draining sounds.

# 

# 2\. Physical Objects (Monoliths)

# Action: Aim at the object and Press Trigger.

# ⚪ Heaven (The Creator): Growth. The object organically increases in size permanently.

# ⚫ Hell (The Corruptor): Destruction. The object explodes (Shatter effect) with a dissonant sound.

# 

# 3\. Virtual Subjectiveness (Player Physics)

# The user's virtual body changes its physical properties based on the world:

# ⚪ Heaven: Fast movement speed, Low Gravity, and high, floating jumps.

# ⚫ Hell: Slow/Heavy movement speed, High Gravity, and short, difficult jumps.

# 

# Developed with Unity \& XR Interaction Toolkit.
